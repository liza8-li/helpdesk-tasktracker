# HelpDesk / TaskTracker — Подсистема управления заявками в службу технической поддержки

> **Концепция:** веб-приложение для приёма, маршрутизации и отслеживания заявок (тикетов) от пользователей во внутреннюю службу технической поддержки. Система обеспечивает полный цикл обработки обращения — от создания заявки до её закрытия с фиксацией всех действий исполнителей.

---

## 📋 Описание системы

HelpDesk/TaskTracker предназначен для автоматизации работы службы технической поддержки. Пользователи могут создавать заявки с описанием проблемы, а операторы и инженеры — назначать исполнителей, отслеживать статусы, добавлять комментарии и закрывать обращения.

### Основные возможности (планируемые)

| Модуль | Функциональность |
|--------|------------------|
| **Аутентификация** | Регистрация, вход, роли (пользователь / оператор / администратор) |
| **Управление заявками** | Создание, просмотр, редактирование, закрытие тикетов |
| **Маршрутизация** | Назначение исполнителя, приоритет, категория обращения |
| **Комментарии и история** | Лента действий по заявке, вложения |
| **Панель администратора** | Управление пользователями, справочниками, отчётами |
| **Уведомления** | Email-оповещения о смене статуса заявки |

## 🛠 Технологический стек

| Слой | Технология |
|------|-----------|
| **Язык программирования** | Python 3.11+ |
| **Web-фреймворк** | Django 5.x (или FastAPI — как альтернатива) |
| **СУБД** | PostgreSQL 16 |
| **ORM** | Django ORM / SQLAlchemy |
| **Фронтенд** | Django Templates + Bootstrap 5 |
| **Аутентификация** | Django Auth / JWT |
| **Контейнеризация** | Docker + docker-compose |
| **VCS** | Git + GitHub |

> *Примечание: стек может быть скорректирован в процессе проектирования. Указанные технологии выбраны как оптимальные для быстрой разработки полнофункционального helpdesk-решения.*
